# Product screenshots

These are captures of the actual SceneSteward frontend rendered locally with a temporary mock API and fictional sample data. They illustrate the interface, not a live production or a verified backend integration. No mock API is shipped or connected to the deployed app.

Each screen is captured in both interface themes; the landing page serves the variant matching the visitor's selected theme:

- workspace-{light,dark}.webp: project participant roster
- consent-{light,dark}.webp: participant consent record
- analytics-{light,dark}.webp: operational overview

Screens were captured at desktop resolution, cropped to the application content, and compressed as WebP. The landing page labels their illustrative data and offers a larger view.
